# Machine Learning desde cero

Implementación, sin librerías de alto nivel, de los fundamentos del ML: descenso de gradiente, SGD, regresión logística con optimizador Adam y PCA + clustering sobre MNIST. Con métricas, fronteras de decisión y visualizaciones.

**Tecnologías:** Python · scikit-learn · Machine Learning
